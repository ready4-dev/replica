# Get this from that

get_this_from_that() is a Get function that extracts data from an
object. Specifically, this function implements an algorithm to get this
from that. The function returns This (an output object of multiple
potential types).

## Usage

``` r
get_this_from_that(
  this_1L_chr = "first",
  that_ls = list(first = 5, second = 6)
)
```

## Arguments

- this_1L_chr:

  This (a character vector of length one), Default: 'first'

- that_ls:

  That (a list), Default: list(first = 5, second = 6)

## Value

This (an output object of multiple potential types)
