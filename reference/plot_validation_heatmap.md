# Plot validation heatmap

Creates a heatmap showing percentage-point differences between observed
and expected distributions across conditioning groups.

## Usage

``` r
plot_validation_heatmap(validation_results, ...)
```

## Arguments

- validation_results:

  Validation results generated by
  [`ratify`](https://ready4-dev.github.io/replica/reference/ratify.md)
  or returned by
  [`validate_synthetic_population_fit`](https://ready4-dev.github.io/replica/reference/validate_synthetic_population_fit.md).

  These results are typically retrieved using:


      procure(
        ADDER,
        slot = "validation_results"
      )

- ...:

  Additional arguments.

## Value

A ggplot object.

## Examples

``` r
if (FALSE) { # \dontrun{
plot_validation_heatmap(
  procure(
    ADDER,
    slot = "validation_results"
  )
)
} # }
```
