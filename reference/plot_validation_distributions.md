# Plot observed and expected distributions

Creates a faceted comparison of observed and expected percentages from
validation results.

## Usage

``` r
plot_validation_distributions(validation_results, ...)
```

## Arguments

- validation_results:

  Validation results generated by
  [`ratify`](https://ready4-dev.github.io/replica/reference/ratify.md)
  or returned by
  [`validate_synthetic_population_fit`](https://ready4-dev.github.io/replica/reference/validate_synthetic_population_fit.md).

  These results are typically retrieved using:


      procure(
        ADDER,
        "validation_results"
      )

- ...:

  Additional arguments.

## Value

A ggplot object.

## Examples

``` r
if (FALSE) { # \dontrun{
plot_validation_distributions(
  procure(
    ADDER,
    "validation_results"
  )
)
} # }
```
